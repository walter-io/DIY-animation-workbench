# 音效库

**这一个目录放的都是「声音文件」，不含任何代码。** 主程序启动时自动扫描，手动增删目录即可，不用改任何代码、不用跑任何命令。

```
音效库/
└─ <你的包目录名>/        ← 一个子目录 = 一个音效包，目录名随便起（中文也行）
   ├─ manifest.json      ← 必填：包的元信息 + 音效清单
   ├─ 轻点.mp3            ← 音频文件，文件名随便起
   └─ 上扬.mp3
```

## 怎么增删音效包

| 想做的事 | 操作 |
|---|---|
| 装一个音效包 | 把整个包目录拷进 `音效库/` |
| 卸载一个音效包 | 把那个目录删掉 |
| 先在本机验一下 | 拷进来 → 刷新页面（或点「拓展包 → 重新扫描」） |

音效包和卡包是**分开的两套**：只想要某些音效，就只拷音效包；两个目录互不牵连。

## manifest.json

```jsonc
{
  "id": "示例包",
  "name": "示例包 · 音效",
  "version": "1.0.0",
  "vendor": "DIY动效编辑台",
  "description": "一句话说明，显示在拓展包面板上",
  "product": { "contact": "", "homepage": "" },  // 纯展示
  "sounds": [
    {
      "id": "crystalTap",           // 唯一 id，不要和内置音效重名
      "name": "晶体轻点",            // 下拉框里显示的名字
      "hint": "清脆的点触声",         // 悬停提示
      "duration": 0.62,             // 时长（秒），用来判断要不要铺满长卡
      "src": "轻点.mp3",             // 音频文件，相对本目录
      "level": 0.85,                // 响度微调 0~1
      "group": "示例包"              // 下拉框分组名，不填就用包名
    }
  ]
}
```

要放几个音效就往 `sounds` 数组里加几项，**一个音效一段配置，不需要写任何 JS**。

## 关于音频文件

- 格式：mp3 最稳（也支持 wav / ogg）。
- 建议先归一化到约 -1.5dBFS 再放进来，避免有的音效炸有的听不见。
- `src` 也可以写绝对地址（`https://你的CDN/xx.mp3`），这样音频可以放在云端按需下载。
- 想让音效在长卡片上持续发声，加 `"sustain": "repeat"`（连贯颗粒流）或 `"loop"`（无缝循环）。

## 注意

- 音效 id **不要和内置音效重名**（重名会被跳过，装不进去）。
- 卡不在这个目录里 —— 动效卡请放邻居的 `动效卡库/`。
- 设置里的「音效总开关」关掉时，不管装了多少音效包，导出都不会烤音轨（配置保留，一键开回来）。

照抄 `示例包/manifest.json` 是最快的起步方式。
