# DIY动效编辑台 · 使用教程

给口播视频做动效的工具：**写好稿子 → 选几张卡 → 导出一段可以直接叠到原片上的视频**。

它不负责拍摄和剪辑，只解决一件事：

> 一段口播里，怎么在合适的时间点弹出「标题卡 / 数据卡 / 对比卡 / 流程卡 / 金句卡」，然后一键导出成素材。

全部在本机运行，稿子和工程都不上传。

---

## 一、启动与关闭

**前置条件：装好 Node.js 20 或更高版本**（[nodejs.org](https://nodejs.org/)，装 LTS 版即可）。

| 系统 | 怎么启动 |
|---|---|
| Windows | 双击 `启动工作台.bat` |
| macOS / Linux | 双击 `启动工作台.command`（或终端里 `./启动工作台.command`） |

会自动打开浏览器访问 `http://localhost:9379/`。**关掉那个黑色命令行窗口就是关闭服务。**

> **首次启动会自动装依赖**，大约 1–3 分钟（只在第一次发生，之后启动就是 3–5 秒）。要手动装也可以，在项目目录里跑 `npm install`。
>
> 装依赖卡住多半是网络问题，先切国内镜像再试：`npm config set registry https://registry.npmmirror.com`

## 三、第一条视频：完整流程

### 第 1 步：导入口播稿

点顶栏 **📝 导入口播稿**，选择 `.srt` 字幕文件。工作台会按字幕时间点生成一句一张字幕卡，全部落在时间轴上。

勾上 **自动生成动效卡** 后，还能顺手按口播语义自动配一整套动效卡。这时要先选 **生成类型**：

| 生成类型 | 生成什么 | 分段密度 |
|---|---|---|
| **常规动效卡** | 常规库的局部小卡（标题 / 数据 / 对比 / 流程 / 列表…），左右交替叠在人物画面上 | 一段一卡，约 12s 一页，卡型多变 |
| **知识动效卡** | 解说库的整页幻灯片（标题页 / 要点页 / 标签页 / 清单页 / 步骤页 / 对比页 / 数据页 / 结尾页） | 一段一页，约 20s 一页，**同一页装更多同类信息** |

两个库的分段规则不一样，这是刻意的：

- 常规库是"叠在画面上的小卡"，画面要跟着口播换得勤一点，所以一页短、卡型多。
- 知识库是"整页 PPT"，一页就是一张画面。分段更粗 —— 一组并列信息（三档排名、四步流程、一串能力）会**落在同一页**，而不是被切成几页；同时每张卡本身能装的条目也更多（清单 6 条 / 步骤 5 格 / 标签 8 个 / 对比左右各 5 条）。

> 导入弹窗里有「匹配预览」，导入前就能看到前 4 张卡按内容匹配成了什么，选哪个库一目了然。
>
> 选知识库时，如果画布背景还是默认的深色舞台色，导入会**自动切到米白**（深色文字压在深色底上会看不见）。之后可在「设置 → 画布背景」随时改回。
>
> 没有 SRT？也可以用剪映 / Whisper 之类工具先导出字幕，或者在左侧「素材库」里直接手动加卡。

### 第 2 步：加动效卡

左侧 **动效库** 分两个库（顶部页签切换）：

- **常规库**：局部效果卡，直接叠在有人物的口播画面上。按分类列着上百张卡（标题、数据、对比、流程、列表、关系、结尾……）。
- **解说库**：知识解说**整页卡**（像在播一页好看的 PPT：大标题页、要点药丸、标签逐个弹出、清单、步骤、对比、数据、结尾页），配合「自定义」出镜小窗，适合不露脸或小窗出镜的知识讲解类视频。
  - 「元素」分类里还有 13 张**零件卡**（大标题、药丸、标签、编号行、步骤芯片、大数字……）和一张「空白底板」—— 先铺底板，再把零件逐张叠上去，就能自己拼出一页。

库内操作两种库一样：

- **加卡**：点一下卡片，它就加到时间轴的播放头位置。
- **换卡**：先选中画面上的某张卡，再点库里另一张卡右侧的 `⇄`。
- **找卡**：顶部搜索框支持按名称、描述、分类搜索。
- 鼠标悬停在卡片上，会弹出这张卡的实时候预览。

### 第 3 步：改内容

选中卡，右侧 **参数面板** 自动列出这张卡能改的东西：

- 文案、标题、副标题
- 数字、单位、百分比
- 颜色（可以单独给一张卡调色，也可以让它跟随主题色）
- 位置、大小、出现方向、时长

改完即时在画面上生效。

### 第 4 步：调出场时间

下方 **时间轴** 上，每一条就是一个片段：

- **拖动** = 改出场时间（延后或提前）
- **拖两端** = 改持续时长
- **按 `S` 键** = 在播放头处把选中的卡一刀切成两段
- **空格** = 播放 / 暂停预览

字幕卡还能一句句单独挪、单独删，互不重叠。

### 第 5 步：定风格

打开顶栏 **设置**，从上到下：

- **画布背景**：整块画布（成片）的底色 —— 跟随主题 / 米白 / 白色 / 黑色 / 自定义。改这一处整片背景都变，非透明导出也会带上；勾了「透明背景」导出时仍然透明。做知识解说片建议选**米白**，卡片保持透明即可
- **主题**：暗色 / 亮色 / 极简（只影响界面与卡片默认配色，不影响画布背景）
- **卡片质感**：毛玻璃 / 实色
- **字体**：黑体 / 衬线 / 等宽
- **卡片背景透明**：0% 是完全不透明背景，100% 则只剩文字浮在画面上
- **口播字幕**：一键「全部显示 / 全部隐藏」—— 隐藏时预览和导出都不画字幕，但文案和时间点都留着，随时能开回来
- **音效**：一键「开 / 关」总开关 —— 关掉后整片不出声、导出也不烤音轨，卡片上配好的音效都保留着

### 第 6 步：导出

点顶栏 **导出**，选择参数后点「开始导出」：

| 选项 | 怎么选 |
|---|---|
| 格式 | **MOV（ProRes 4444）**：要透明、要进剪映叠层就选它<br>**WebM（VP9）**：也要透明，文件更小<br>**MP4（H.264）**：不透明，出得最快，适合先看效果 |
| 透明背景 | 勾上导出的背景是透明的，可以直接叠在原片上。**注意：透明导出不会带上你导入的视频 / 图片素材** |
| 帧率 | 一般 30 够用 |
| 导出速度 | 1x 最稳（成片用这个）；2x / 3x 更快，运动画面可能略跳。透明导出是逐帧截图，速度固定 |
| 音效烤入 | 可以不填；工程里的动效卡音效会自动合成一条音轨进成片。也可以另外选一个音频文件混进去 |

导出在本机渲染，完成后浏览器自动下载，并自动校验编码是否正确。

> **导出要在这台电脑上装三样东西**（编辑、预览不需要，只有导出需要）：
> `playwright` + `chromium` 浏览器 + `ffmpeg`。
> 没装的话点「开始导出」会看到：
> `导出出错：{"error":"导出需要宿主安装 playwright 与 chromium（未检测到 playwright）"}`
> —— 这只是说明本机缺导出用的无头浏览器，**不影响你继续编辑和预览**。
> 按提示装齐后重启工作台即可；装法见 [`DEVELOPMENT.md` §7「运行前置」](./DEVELOPMENT.md#7-导出管线)。

## 四、常用操作速查

| 操作 | 怎么做 |
|---|---|
| 播放 / 暂停 | 空格 |
| 撤销 / 重做 | `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z`（或 `Ctrl + Y`） |
| 复制选中卡 | `Ctrl/Cmd + D` 或 `Ctrl/Cmd + C` |
| 在播放头处切开选中卡 | `S` |
| 删除选中内容 | `Delete` / `Backspace`（优先删关键帧，其次删片段） |
| 改左右面板宽度 | 拖面板边缘，双击恢复默认 |
| 保存 / 回溯版本 | 顶栏 💾 / 🕘 |

> 工程会自动存在本机浏览器里，关掉页面下次打开还在。要做大改动前建议先 💾 存一版。

## 五、素材库：图片、视频、垫底画面

左侧 **素材库** 页签里可以导入本地图片和视频：

- 拖到画布上就是一个素材片段，能缩放、位移、加关键帧动画。
- 导入一段视频做「垫底」，动效卡就叠在它上面；顶栏「视频」菜单可以调它的显示与透明度。
- **导出提醒**：勾了「透明背景」时，素材画面会被整段排除（透明片本来就是拿来叠到别的内容上的），要让视频出现在成片里就别勾透明。

## 六、模板：把一次编排变成可复用资产

做完一条满意的片子后：

1. 顶栏 **模板** → 存成模板；
2. 下一条同类视频打开工作台 → **模板** → 套用；
3. 替换文案即可，卡的位置、时长、风格全部沿用。

适合「每周固定栏目」「系列口播」这类成批量的场景。

## 七、拓展包：把卡和音效当「文件夹」来管

工作台把「动效卡」和「音效」拆成了两个独立目录，就放在项目根目录：

```
动效卡库/          ← 每个子文件夹 = 一个卡包
音效库/            ← 每个子文件夹 = 一个音效包
```

**增删全靠拷文件夹 —— 不用改任何代码，也不用跑任何命令。**

- 想装上一个卡包 / 音效包 → 把包文件夹拷进 `动效卡库/`、`音效库/`；
- 想卸掉 → 把对应文件夹删掉或整个移走；
- 拷完刷新一下页面：新的卡就出现在动效库，新的音效就出现在音效下拉里。

左侧 **拓展包** 页签里能看到当前装了哪些包，并单独 **启用 / 停用**：

- 停用后，它带来的卡和音效立即从库里消失；
- **停用不会破坏已有工程**：已经排好的卡只是暂时不显示，重新启用就恢复；
- 装过的机器和没装的机器之间来回拷工程也没关系，卡不会丢。

两个目录里各有 `README.md` 写清了包的文件格式，`示例包` 是可以直接照抄的样板。

## 八、常见问题

**Q：导出的MOV在剪映里不透明？**
用 MOV + ProRes 4444，并且勾了「透明背景」。如果走的是 MP4，就没有透明通道（格式限制）。

**Q：为什么片子里没有我导入的视频？**
勾了「透明背景」。透明导出会排除素材画面，取消勾选即可。

**Q：字幕一键隐藏了，还能找回来吗？**
能。设置里点回「全部显示」，一句不少。

**Q：音效根本没声音？**
先看设置里的音效总开关是不是被关了；再看单卡上是不是设了静音。导出时要勾上音效才会进成片（默认的动效卡音效会自动合成）。

**Q：导出要很久？**
时长越长、帧率越高越久。先用 MP4 + 1x 出短片段验证效果，定稿再出透明 MOV。

**Q：点导出报 `导出需要宿主安装 playwright 与 chromium（未检测到 playwright）`？**
本机没装导出用的无头浏览器。装上 `playwright` + `chromium` 浏览器 + `ffmpeg` 三样，重启工作台即可。
在这之前，编辑、预览、时间轴、动效库都能正常用，只有「导出成片」这一步被挡住。
步骤见 [`DEVELOPMENT.md` §7「运行前置」](./DEVELOPMENT.md#7-导出管线)。

**Q：改动效卡的文字颜色 / 强调色，编辑台突然整个白屏了？**
旧版本的偶发问题（hf 系列卡片改参数时 iframe 换页有空档，React 会因此卸载整个界面），**已修**。
现在即使某张卡出问题，也只会变成「这一张卡显示报错 + 一个「重试」按钮」，其余部分照常可用。

**Q：换了台电脑，工程能带走吗？**
工程存在浏览器本地。要迁移就用 💾 存版本后导出工程文件，在新机器上拷过去（或用顶栏的模板功能重建）。

**Q：卡片的字超框了怎么办？**
先在右侧参数面板调「字号 / 行距 / 宽度」，多数卡支持自适应；仍然不行就换成信息量更小的卡（比如把四行合并成三行）。
